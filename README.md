# 🎵 Spotify Data Analysis Using Excel

## 📌 Project Overview

This project focuses on analyzing Spotify dataset using Microsoft Excel to extract insights about music trends, popular genres, and artist performance.

---

## 📊 Dataset

* Dataset contains 10,000+ records of songs
* Includes attributes like artist name, genre, popularity, streams, and release year

---

## ⚙️ Tools Used

* Microsoft Excel
* Pivot Tables
* VLOOKUP
* Data Cleaning Techniques

---

## 🔍 Steps Performed

1. Cleaned the dataset by handling missing values and removing duplicates
2. Used VLOOKUP to merge and organize data
3. Created Pivot Tables to analyze trends
4. Performed data analysis on genres, artists, and streaming patterns

---

## 📈 Key Insights

* Identified top-performing music genres based on streams
* Analyzed artist popularity trends over time
* Observed monthly and yearly streaming patterns

---

## 🎯 Outcome

The project helped in understanding how data analysis can be used to identify trends in the music industry and support data-driven decision making.
